# MY LIFE ROUTINE（無料PWA）

## このフォルダの内容
- `index.html`：アプリ本体
- `manifest.webmanifest`：ホーム画面追加用の設定
- `sw.js`：オフライン表示用のService Worker
- `icon-192.png`・`apple-touch-icon.png`：アプリアイコン

## 無料で公開する方法（GitHub Pages）
1. GitHubで無料アカウントを作成・ログインします。
2. 新しい公開リポジトリを作成します（例：my-life-routine）。
3. このフォルダ内の4ファイルをリポジトリ直下にアップロードします。
4. リポジトリの Settings → Pages を開きます。
5. Build and deployment の Source を「Deploy from a branch」にし、Branchを「main」、フォルダを「/(root)」にして Save。
6. 公開された `https://ユーザー名.github.io/my-life-routine/` をiPhoneのSafariで開きます。
7. Safariの共有ボタン →「ホーム画面に追加」→「追加」を選びます。

## iPhoneでの使い方
ホーム画面に追加したアイコンから開いてください。予定やタスクの変更は、その端末のブラウザ内（localStorage）に保存されます。ブラウザの履歴・Webサイトデータを消去すると、保存内容も消える場合があります。

## 通知について（重要）
この無料版は、アプリ画面を開いている間に、設定時刻になったらブラウザ通知を表示する仕組みです。iOSの省電力・バックグラウンド制限により、アプリを閉じている間の定時通知は保証できません。アプリを閉じていても確実に通知するには、Web Push用のサーバーや外部通知サービス等が必要になり、無料枠・仕様変更の確認が別途必要です。

## 初期スケジュール
- 起床 6:30、就寝 23:00
- 植物ショップ：月・火・水・金（9:30外出〜18:30帰宅の枠）
- メルカリ実務：木・土・日（撮影・採寸・リサーチ等）
- 毎日3点出品
- 家事、ストレッチ、家族時間を設定

初期時間割は仮設定です。アプリ内の「編集」から実際の生活に合わせて調整してください。
